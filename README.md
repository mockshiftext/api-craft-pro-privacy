Privacy Policy for API Craft Pro

Last Updated: November 2026

API Craft Pro is a local-first developer productivity Chrome Extension designed with user privacy as a top priority.

1. No Personal Data Collection

We do not collect, track, store, or transmit any of your personal data, browsing history, intercepted API requests, headers, or payloads to any external servers.

2. Local Storage Only

All captured API traffic, configurations, and user-defined mock rules are processed and stored strictly locally on your machine using Chrome's native chrome.storage.local and chrome.storage.sync APIs.

3. License Verification

When activating a Pro license key, only the license key string is securely transmitted to our payment processor Lemon Squeezy (api.lemonsqueezy.com) solely to verify license validity and activation status. No personal browsing or network data is included in this request.
